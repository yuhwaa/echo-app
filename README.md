# Echo — Content Operations Dashboard

A publication tracking tool built for investment management content teams. 
Inspired by the workflow behind Oaktree Capital's Insights publications.

## Features
- Track publications through In Queue → In Progress → Live
- Production checklists per publication
- Inline editing for titles, dates, and status
- Team comments per task
- File attachments per task (in progress)

## Built with
Next.js · TypeScript · Supabase · shadcn/ui · Tailwind CSS
